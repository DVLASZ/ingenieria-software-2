# Laboratorio de Ingeniería de Software II

Universidad del Cauca — Programa de Ingeniería de Sistemas — Periodo 2-2026.

Este repositorio reúne las actividades **sueltas** (talleres, parciales,
ejercicios de laboratorio) desarrolladas a lo largo de la materia. Cada
actividad vive en su propia carpeta, con su propio `README.md` explicando
qué es, cómo ejecutarla y cómo se relaciona con la guía correspondiente.

> El **proyecto de curso** ("Sistema para la Gestión, Validación y
> Administración de un Banco de Preguntas para la Preparación de las
> Pruebas Saber Pro") tiene su propio repositorio aparte, ya que es un
> desarrollo continuo a lo largo del semestre y merece su propio historial
> de commits, issues, etc. Enlace: *(pendiente por crear)*.
