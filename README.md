# Ingeniería de Software II: laboratorio

Repositorio de los trabajos del laboratorio de Ingeniería de Software II, Universidad del Cauca (periodo 2026.2).

> El **proyecto de curso** (sistema para la gestión, validación y administración de un banco de preguntas para la
> preparación de las pruebas Saber Pro) tiene su propio repositorio:
> [`banco-preguntas-saberpro`](https://github.com/DVLASZ/banco-preguntas-saberpro). Nació del código del Taller 4 y
> evolucionó a un monolito modular y después a microservicios.

## Contenido

| Carpeta | Qué hay |
|---|---|
| [`talleres/`](talleres/README.md) | Los talleres del laboratorio, uno por carpeta, con su README e informe |
| [`parciales/`](parciales/README.md) | Los parciales prácticos, con su proyecto y documento |

## Entorno

Los trabajos con código son proyectos Maven independientes, para Java 17 o superior. Cada carpeta indica en su
README cómo compilarla y ejecutarla.
