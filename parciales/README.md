# Parciales

Parciales prácticos del laboratorio de Ingeniería de Software II. Cada carpeta contiene el proyecto entregado y el
documento con la sustentación del proceso.

| Parcial | Corte | Contenido |
|---|---|---|
| [Parcial 1](Parcial-01-Corte1) | Primer corte | Proyecto Maven `lisw2_parcial01_davilaE` (banco de preguntas con un pipeline de filtros de validación y pruebas unitarias) y documento `lisw2_parcial01_davilaE.docx` |

## Entorno

Java 17 o superior y Maven. Cada parcial es un proyecto Maven independiente: se compila con `mvn test` desde la
carpeta del proyecto.
