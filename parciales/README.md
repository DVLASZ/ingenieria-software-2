# Parciales

Parciales prácticos del laboratorio de Ingeniería de Software II. Cada carpeta contiene el proyecto entregado y el
documento con la sustentación del proceso.

| Parcial | Corte | Contenido |
|---|---|---|
| [Parcial 1](Parcial-01-Corte1) (cuenta como el Taller 7) | Primer corte | Enunciado del grupo B, proyecto Maven `lisw2_parcial01_davilaE` (banco de preguntas con un pipeline de filtros de validación y pruebas unitarias) y documento `lisw2_parcial01_davilaE.docx` |
| [Parcial 2](Parcial-02-Corte2) | Segundo corte | Enunciado del grupo B, proyecto Maven `lisw2_parcial02_davilaE` (tres microservicios y un módulo de dominio: Builder y State, REST y RabbitMQ, y persistencia JPA en H2), colección de Postman y documento `lisw2_parcial02_davilaE.docx` con las evidencias |

## Entorno

Java 17 o superior y Maven. Cada parcial es un proyecto Maven independiente: se compila con `mvn test` desde la
carpeta del proyecto.
